# Fokus ⏱️

Aplicação web de produtividade que combina uma lista de tarefas com três modos de cronômetro para auxiliar na organização do tempo, concentração e descanso durante os estudos ou trabalho.

## ✨ Funcionalidades

- ⏱️ **Cronômetro de foco:** temporizador para períodos de concentração.
- ☕ **Descanso curto:** pausa de 5 minutos.
- 🌙 **Descanso longo:** pausa de 15 minutos.
- 📝 **Lista de tarefas:** adicione, edite e selecione tarefas para acompanhar suas atividades.
- ✅ **Conclusão automática:** ao finalizar o cronômetro de foco, a tarefa selecionada é marcada como concluída.
- 💾 **Persistência de dados:** as tarefas ficam salvas no `localStorage`, mesmo após recarregar a página.
- 🗑️ **Gerenciamento de tarefas:** remova tarefas concluídas ou limpe toda a lista.
- 🎵 **Música ambiente:** opção para reproduzir música durante as sessões de foco.
- 🔊 **Efeitos sonoros:** sons para iniciar, pausar e finalizar o cronômetro.
- 🎨 **Interface dinâmica:** textos, imagens e estilos se adaptam ao modo selecionado.

## 🚀 Como executar

1. Clone o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Fokus-projeto-base
   ```

3. Abra o arquivo `index.html` no navegador.

   Você também pode utilizar a extensão **Live Server** no Visual Studio Code para executar o projeto durante o desenvolvimento.

## 💡 Como utilizar

1. Escolha entre os modos **Foco**, **Descanso curto** e **Descanso longo**.
2. Clique em **Começar** para iniciar o cronômetro e em **Pausar** para interrompê-lo.
3. Ative a opção de música, se desejar.
4. Adicione tarefas e selecione aquela em que deseja trabalhar.
5. Ao finalizar uma sessão de foco, a tarefa selecionada será marcada como concluída.
6. Utilize o menu de opções para limpar as tarefas concluídas ou remover todas as tarefas.

## 🎯 Objetivo do projeto

Projeto desenvolvido para praticar conceitos fundamentais de desenvolvimento front-end, incluindo manipulação do DOM, eventos, temporizadores, armazenamento local e criação de interfaces interativas com JavaScript.
